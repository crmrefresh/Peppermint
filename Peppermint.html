Getting this into Google Sheets with the template formatting intact

The way that keeps everything. In Drive, make a copy of TEMPLATE - Past Client Log, rename it for the agent, then paste the copied rows into cell C3. Starting at C leaves the Exclude and Since Sold checkboxes, the banner and the header formatting untouched — you are only filling in First Name through Tags.

Bringing the green with it. A values-only paste carries no colour, so add it as a rule once per sheet: select A3:Q, then Format › Conditional formatting › Custom formula is, and fill with #dbffda.

=OR($N3<>"",$O3<>"")

The rule greens any row that came back with a phone or an email, which is nearly all of them. A handful of rows match a contact who has neither — those stay white under the rule, and the Needs an eyeball filter above lists them.

The two review blocks at the bottom. Deals with no agent data are yellow, with both parties listed and the Buyer / Seller column set to Unknown — the closing date sits in both date columns so you keep whichever applies. Deals with no client name are orange, one row each, with Data Not Available in First Name. Each block has its own heading row. A values-only paste brings the text but not the merge or the colour, so the .xlsx below is the better route when these blocks are present.

Or skip the rule. Download the .xlsx and drop it into Drive, then open it with Sheets. The banner, header colour, column widths, frozen header, date and dollar formats and the real green fills all survive the import. The two checkbox columns arrive as plain TRUE/FALSE — select A3:B and use Insert › Checkbox to turn them back into tick boxes.
